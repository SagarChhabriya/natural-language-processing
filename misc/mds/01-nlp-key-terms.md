# Key NLP & AI Terms: Text and Speech Processing

## Speech & Audio

- **Transcription**: Turning spoken words into written text  
  *Example: Audio recording → Text*

- **Text-to-Speech (TTS)**: Turning written text into spoken words  
  *Example: Text response → Voice output*


##  Language Conversion

- **Translation**: Changing text from one language to another (meaning changes)  
  *Example: "Good morning" → "Buenos días"*

- **Transliteration**: Writing words from one alphabet/script into another (sounds stay the same)  
  *Example: "नमस्ते" → "namaste"*


##  Changing Text Form

- **Summarization**: Making long text shorter while keeping the main idea  
  *Example: Article → Summary*

- **Paraphrasing**: Rewriting text using different words but same meaning  
  *Example: "She is very tired" → "She’s exhausted"*

- **Text Generation**: Creating new text based on some input or prompt  
  *Example: Starting a story and AI continues it*

- **Text Simplification**: Making complex text easier to understand  
  *Example: Difficult text → Simple text*


##  Extracting Information

- **Named Entity Recognition (NER)**: Finding names, places, or organizations in text  
  *Example: "Apple is in California" → Apple (Company), California (Place)*

- **Relation Extraction**: Finding how entities are connected  
  *Example: "Elon Musk founded SpaceX" → (Elon Musk, founded, SpaceX)*

- **Intent Detection**: Understanding what the user wants  
  *Example: "Book a flight" → intent: book_flight*

- **Slot Filling**: Picking out important details from a sentence  
  *Example: "Book a flight to Paris" → destination: Paris*


##  Understanding & Categorizing Text

- **Embedding**: Turning text into numbers so computers can understand it  
  *Example: "king" → [0.25, 0.81, ...]*

- **Text Classification**: Putting text into categories or labels  
  *Example: "You won a prize!" → spam*
